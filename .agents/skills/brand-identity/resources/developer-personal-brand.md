## 📌 1. Visión y Filosofía de Marca Personal

Esta guía formaliza los estándares de autoría, excelencia técnica, arquitectura y firma profesional de **Rogerr Carvajal** como desarrollador especializado en la creación de soluciones basadas en **Modelos de Inteligencia Artificial, Agentes Inteligentes y Arquitecturas Nativas de Nube (Cloud-Native)**.

Cada línea de código, módulo arquitectónico, componente de interfaz o documentación técnica generada en este o futuros proyectos debe reflejar esta impronta de ingeniería avanzada:

### Pilares de Marca Personal:
1. **Enfoque Agent-First & Multi-Agente:**
   - La arquitectura no se improvisa: se modela para que agentes autónomos especializados (`solution-architect`, `python-ai-engineer`, `backend-core-dev`, `ui-ux-designer`, `qa-security-auditor`) colaboren armónicamente bajo contratos claros y tipados.
2. **Arquitectura Cloud-Native & Multi-Cloud:**
   - Proyectos diseñados bajo los 12 factores: empaquetado en contenedores OCI (Docker multi-stage con usuario no root), endpoints con variables de puerto dinámico (`PORT`), healthchecks nativos y listos para ser desplegados desde GitHub hacia Google Cloud Platform (GCP Cloud Run), AWS (App Runner / ECS), Azure o PaaS modernas.
3. **Ingeniería Disciplinada y Tipado Estricto:**
   - Cero código débil o no tipado. Python 3.11+ con Pydantic v2 y asincronía (`async def`), PHP 8.2+ con strict types (`declare(strict_types=1);`), TypeScript fuertemente tipado.
4. **Seguridad Zero-Trust y Resiliencia:**
   - Cero credenciales o secretos en código fuente. Parámetros vinculados obligatorios en base de datos (PDO / ORM seguro), manejo exhaustivo de excepciones, validación estricta de esquemas y reintentos con backoff exponencial en llamadas a LLMs.
5. **Trazabilidad y Calidad 100%:**
   - Metodología de desarrollo en bucle guiado por pruebas hasta alcanzar 0 fallos. Trazabilidad completa a issues (`Ref #X`) y entrega profesional mediante GitHub MCP.
6. **Estética Visual Premium:**
   - Interfaces memorables con modo oscuro futurista, glassmorphism (`backdrop-filter: blur(12px)`), gradientes cyan/indigo y micro-animaciones dinámicas con accesibilidad WCAG 2.1 AA.
